# Intern

A context-aware AI knowledge assistant.

Intern is designed to answer questions using multiple knowledge sources:

- General LLM knowledge
- User-selected knowledge bases
- External information sources

The initial version focuses on a local Retrieval-Augmented Generation (RAG)
system that can run entirely on a user's machine.

## Core Concept

The user can control which knowledge sources are used:

```text
Knowledge Base:  ON / OFF
Internet:        ON / OFF
